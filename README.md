# The One-Liner Groan-Off

[![make.fun](https://make.fun/badge.svg)](https://make.fun/competitions/u-alfasurya91-the-one-liner-groan-off-5a1febd5)

One original dad joke, one line, for [The One-Liner Groan-Off](https://make.fun/competitions/u-alfasurya91-the-one-liner-groan-off-5a1febd5) on make.fun.

## The joke

> I asked the calendar for a date, but it said it was already booked.

## How it works

`main.py` writes that single line to `/output/entry.txt` — deterministic,
no network, no input. Run it with `python3 main.py`.
